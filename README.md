# D.S

A collection of C++ programs covering fundamental programming concepts, data structures, and object-oriented programming.

## What's Inside

This repository contains practice programs written in C++ that demonstrate core language features and problem-solving patterns.

### Programs

| File | Concept |
|---|---|
| `hello.cpp` | Basic program structure and I/O |
| `datatypes.cpp` | C++ data types |
| `array.cpp` | Arrays and user input |
| `count.cpp` | Counting / loop logic |
| `even.cpp` | Conditional checks |
| `primeusingclass.cpp` | Prime numbers with classes |
| `fibonacciusingclass.cpp` | Fibonacci series using classes |
| `factusingclass.cpp` | Factorial with classes |
| `gcdusingclass.cpp` | GCD with classes |
| `grades.cpp` | Grade calculation |
| `readnum.cpp` | Number input handling |
| `function.cpp` | Functions |
| `functionoverload.cpp` | Function overloading |
| `functiontemplate.cpp` | Function templates |
| `constructoroverload.cpp` | Constructor overloading |
| `defaultconstructor.cpp` | Default constructors |
| `copyconstructor.cpp` | Copy constructors |
| `default.cpp` | Default parameters |
| `shop.cpp` | Switch-case menu program |

## Topics Covered

- C++ syntax and I/O
- Control structures: loops, conditionals, switch-case
- Arrays
- Functions and function overloading
- Function templates
- Classes and objects
- Constructors: default, overloaded, copy
- Object-oriented programming basics

## How to Compile

```bash
g++ -std=c++11 <filename>.cpp -o <output>
./<output>
```

Example:

```bash
g++ -std=c++11 fibonacciusingclass.cpp -o fibonacci
./fibonacci
```

## Requirements

- C++11 or later
- g++ or any standard C++ compiler
